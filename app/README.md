# CafeTrip (ต้นแบบ)

แอปรวมคาเฟ่น่าไปทั่วไทย พร้อมมุมถ่ายรูป เวลาแสงสวย และวางทริป

## วิธีเปิด
```bash
cd app
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000 (หรือดับเบิลคลิก `index.html` ก็ได้)

## ไฟล์
- `index.html` โครงหน้า
- `styles.css` หน้าตา (รองรับมือถือ + โหมดมืด)
- `app.js` การทำงาน: ค้นหา กรอง แผนที่ รายละเอียดร้าน ทริป
- `data/cafes.js` ข้อมูลร้าน (**ตอนนี้เป็นร้านสมมติ** ต้องแทนด้วยร้านจริง)

## เพิ่มร้าน
คัดลอกหนึ่งก้อนใน `data/cafes.js` แล้วแก้ข้อมูล พิกัด lat/lng หาได้จาก Google Maps (คลิกขวาที่ร้าน)
