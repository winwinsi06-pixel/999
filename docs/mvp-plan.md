# แผน MVP: แอปรวมคาเฟ่น่าไปทั่วไทย

ชื่อชั่วคราว: **CafeTrip**

## 1. ปัญหาที่แก้

คนเจอคาเฟ่สวยจาก TikTok / Lemon8 / IG แต่ต้องจดชื่อร้านแล้วไปค้นใน Google Maps เอง
และไม่รู้ว่าร้านไหนถ่ายรูปสวย ควรไปกี่โมง หรือจะไปหลายร้านในวันเดียวยังไง

## 2. กลุ่มผู้ใช้

1. **คนไทยสายคาเฟ่ฮอปปิ้ง** อายุ 18–35 เที่ยววันหยุด ชอบถ่ายรูปลงโซเชียล
2. **นักท่องเที่ยว** ที่อยากหาคาเฟ่ดังในจังหวัดที่ไป (เฟสถัดไปเพิ่มภาษาอังกฤษ)

## 3. จุดต่างจาก Wongnai / Google Maps

| | Wongnai / Google Maps | CafeTrip |
|---|---|---|
| ข้อมูลหลัก | รสชาติ ราคา รีวิว | **มุมถ่ายรูป เวลาแสงสวย ช่วงคนน้อย** |
| คัดร้าน | ทุกร้าน | **เฉพาะร้านที่น่าไป** (คัดแล้ว) |
| วางแผน | ทำลิสต์เอง | **จัดทริปคาเฟ่ 1 วัน** ให้อัตโนมัติ |

## 4. ฟีเจอร์ MVP (เวอร์ชันแรก)

ต้องมี:
- [x] รายการคาเฟ่ กรองตาม **จังหวัด** และ **สไตล์** (มินิมอล, สวน/ธรรมชาติ, วินเทจ, วิวทะเล/ภูเขา ฯลฯ)
- [x] หน้ารายละเอียดร้าน: เวลาเปิดปิด, วันหยุด, งบต่อคน, **มุมถ่ายรูปเด่น**, **เวลาแสงสวย**, **ช่วงคนน้อย**, ลิงก์ Google Maps
- [x] แผนที่ปักหมุดร้าน
- [x] ปุ่ม "เพิ่มในทริป" แล้วดูทริปเรียงตามเวลา
- [x] ค้นหาชื่อร้าน

เฟสถัดไป:
- [ ] แชร์ลิงก์ TikTok / Lemon8 แล้วระบบดึงชื่อร้านให้ (AI)
- [ ] จัดเส้นทางทริปอัตโนมัติตามระยะทาง + เวลาเปิดปิด
- [ ] ผู้ใช้ส่งรูปมุมถ่ายรูป / รีวิว
- [ ] ระบบบัญชีผู้ใช้ เก็บทริปข้ามเครื่อง
- [ ] ภาษาอังกฤษ / จีน
- [ ] หน้าร้านค้าสำหรับเจ้าของคาเฟ่ (โปรโมต = รายได้)

## 5. เทคโนโลยี

| ช่วง | เลือกใช้ | เหตุผล |
|---|---|---|
| ต้นแบบ (ตอนนี้) | HTML + CSS + JavaScript ล้วน, แผนที่ Leaflet + OpenStreetMap | ไม่ต้องติดตั้งอะไร เปิดไฟล์ก็ใช้ได้ แก้ง่ายสำหรับมือใหม่ |
| เวอร์ชันจริง | เว็บแอป (Next.js) หรือ Flutter ถ้าต้องการแอปมือถือ | ทำได้ทั้งเว็บและมือถือ |
| ฐานข้อมูล | Supabase (ฟรีช่วงแรก) | มีระบบล็อกอิน + ฐานข้อมูล + เก็บรูป |
| ข้อมูลร้าน | คัดเองก่อน 50–100 ร้าน แล้วใช้ Google Places API เติมเวลาเปิดปิด | Places API มีค่าใช้จ่ายตามการใช้งาน |

## 6. ข้อมูลร้าน (โครงสร้าง)

ดู `app/data/cafes.json` แต่ละร้านมี: ชื่อ, จังหวัด, อำเภอ/ย่าน, พิกัด, สไตล์, เวลาเปิดปิด,
วันหยุด, งบต่อคน, มุมถ่ายรูปเด่น, เวลาแสงสวย, ช่วงคนน้อย, ลิงก์ Google Maps, แหล่งที่มา (TikTok/IG)

> ข้อมูลในต้นแบบตอนนี้เป็น **ร้านสมมติ** ใช้ทดสอบหน้าจอเท่านั้น ต้องแทนด้วยร้านจริงที่ตรวจสอบแล้ว

## 7. แผนงาน 4 สัปดาห์

| สัปดาห์ | งาน |
|---|---|
| 1 | เก็บข้อมูลคาเฟ่จริง 30 ร้าน ใน 1–2 จังหวัด (เช่น เชียงใหม่ + กรุงเทพ) ไปถ่ายรูป/จดมุมถ่ายรูปเอง |
| 2 | ใส่ข้อมูลจริงลงต้นแบบ ให้เพื่อน 10 คนลองใช้ เก็บ feedback |
| 3 | ปรับตาม feedback, ทำฐานข้อมูล Supabase, deploy ขึ้นเว็บ (Vercel / Netlify ฟรี) |
| 4 | ทำเพจ TikTok / IG ของแอปเอง โพสต์ "ทริปคาเฟ่ 1 วัน" ดึงคนเข้าเว็บ |

## 8. วัดผลว่าไปถูกทาง

- คนที่เข้าเว็บแล้วกด "เพิ่มในทริป" อย่างน้อย 1 ร้าน > 30%
- คนกลับมาใช้ซ้ำภายใน 2 สัปดาห์ > 20%
- เจ้าของคาเฟ่ติดต่อขอลงร้านเอง = สัญญาณว่ามีโอกาสหารายได้
