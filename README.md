# สำรวจแอปที่คนใช้มากที่สุด (ทั่วโลก vs ไทย)

ข้อมูลรวบรวม ณ พฤศจิกายน 2026 จากแหล่งเผยแพร่สาธารณะ

| ไฟล์ | เนื้อหา | แหล่ง |
|---|---|---|
| `data/global_mau.csv` | ผู้ใช้ต่อเดือน (พันล้าน) 10 แอปแรกทั่วโลก | ค่าประมาณจากบทความสรุปหลายแหล่ง |
| `data/global_downloads_2025.csv` | ยอดดาวน์โหลดทั้งปี 2025 (ล้านครั้ง) | AppMagic |
| `data/thailand_usage.csv` | % ผู้ใช้อินเทอร์เน็ตไทย (16+) ที่ใช้แต่ละแอป | DataReportal Digital 2027 Thailand |
| `data/thailand_favorite.csv` | % ที่เลือกเป็นแอปโปรด | DataReportal Digital 2027 Thailand |
| `data/thailand_commerce.csv` | คะแนนแบรนด์ช้อปปิ้ง/เดลิเวอรี | YouGov Thailand (ต.ค. 2024–ต.ค. 2025) |

`report/index.html` คือโค้ดหน้ารายงานที่ใช้ในแดชบอร์ดออนไลน์

> ตัวเลขแต่ละชุดวัดคนละแบบ เทียบข้ามชุดโดยตรงไม่ได้ และควรตรวจกับรายงานต้นฉบับก่อนนำไปอ้างอิง
